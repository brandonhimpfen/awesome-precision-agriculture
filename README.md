> A curated list of resources for precision agriculture, variable rate technology, spatial soil mapping, machine guidance, and site-specific crop management.

Precision agriculture leverages spatial data, sensor networks, and targeted application technology to optimize field-level management, maximize input efficiency, and minimize environmental impact. This list is intended for precision agronomists, GIS specialists, agricultural engineers, and smart farming developers.

## Spatial Analysis & GIS Tools

Open-source GIS packages and spatial data processing tools tailored for site-specific agricultural mapping and field zoning.

- [QGIS AgGateway Plugins](https://github.com/AgGateway) — Specialized GIS extensions designed to parse precision agriculture data standards, yield maps, and field boundary files.
- [SAGA GIS](https://sourceforge.net/projects/saga-gis/) — System for Automated Geoscientific Analyses featuring advanced terrain analysis and spatial interpolation tools for soil and elevation modeling.
- [Agros2D](https://github.com/hpfem/agros2d) — Multi-field finite element processor designed for modeling physical fields in sensor design and agricultural applications.
- [WhiteboxTools](https://github.com/jblindsay/whitebox-tools) — Advanced geospatial data analysis engine providing high-performance tools for digital elevation models and precision hydrology mapping.

## Guidance & Machine Control

Open-source auto-steer, GPS guidance, and tractor control software for field machinery.

- [AgOpenGPS](https://github.com/mharws/AgOpenGPS) — Open-source tractor autosteer and section control software using GNSS receivers and microcontroller hardware.
- [ISO-BUS Stack (ISOBUS)](https://github.com/Open-ISOBUS/Open-ISOBUS) — Open-source implementation of ISO 11783 standards enabling standardized communication between tractors, implements, and virtual terminals.
- [RTKLIB](https://github.com/tomojitakasu/RTKLIB) — Open-source program package for standard and precise positioning with GNSS supporting real-time kinematic (RTK) positioning for centimeter accuracy.

## Soil Mapping & Sensing

Hardware schemas, protocols, and data models for proximal soil sensing and moisture monitoring.

- [SoilGrids API](https://github.com/ISRICWorldSoil/SoilGrids250m) — Automated system for global soil mapping delivering spatial soil property predictions at 250m resolution.
- [Open-Ag-Sensors](https://github.com/openag) — Open hardware and firmware blueprints for soil electrical conductivity (EC) and soil moisture monitoring probes.
- [R-Soil](https://github.com/CranfieldUni/soil-r) — R packages specifically created for digital soil mapping, spatial pedometrics, and soil landscape modeling.

## Variable Rate Systems

Tools and algorithms for generating variable rate application (VRA) prescriptions for seed, fertilizer, and crop protection.

### Prescription Maps

- [Field-Prescription-Generator](https://github.com/opengeos/geemap) — Python utilities leveraging Sentinel and Landsat imagery to automatically delineate yield zones and build ISO-XML prescriptions.
- [Agro-VRA Tools](https://github.com/qgis/QGIS) — Processing scripts for converting vegetation index maps into actionable rate controller maps.

### Nutrient Management

- [Nutrient-Stewardship-Models](https://github.com/USDA-ARS) — Algorithmic models built on the 4R Nutrient Stewardship principles to optimize fertilizer application timing and rate.
- [APSIM (Agricultural Production Systems sIMulator)](https://github.com/APSIMInitiative/ApsimX) — High-precision modeling framework that simulates biophysical processes in agricultural systems to guide nitrogen variable rating.
